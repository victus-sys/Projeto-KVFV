# Hotel Alba

Projeto acadêmico da disciplina de Análise e Projeto de Sistemas. A versão atual permite cadastrar, consultar, editar e excluir hóspedes em uma aplicação desktop para o Hotel Alba.

## Tecnologias

- Java 21 e JavaFX
- SQLite com JDBC
- Maven

## Como executar

Com Java 21 e Maven instalados, abra o terminal na pasta `projeto kvfv/sistema-hotel-semana1` e execute:

```bash
mvn javafx:run
```

O banco SQLite é criado na pasta `data/` durante a inicialização.
