# Hotel Alba

Sistema acadêmico de gerenciamento de hotel em Java 21, com interface desktop JavaFX e uma interface web complementar. As duas versões usam SQLite local.

Consulte o [README técnico](projeto%20kvfv/sistema-hotel-semana1/README.md) para instalação, execução, perfis e testes. A implementação mantém o foco no projeto desktop exigido pela disciplina; os diagramas serão revisados depois que as funcionalidades estiverem fechadas.
