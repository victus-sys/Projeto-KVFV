# Product Backlog Inicial

Histórias de usuário do Hotel Alba, organizadas por prioridade. Os itens descrevem o escopo planejado; nem todos estão implementados na versão atual.

| ID | História de usuário | Prioridade |
|---|---|---|
| HU01 | Como administrador ou recepcionista, quero entrar com meu usuário e perfil para acessar o sistema. | Alta |
| HU02 | Como recepcionista, quero cadastrar hóspedes para manter seus dados registrados. | Alta |
| HU03 | Como recepcionista, quero consultar hóspedes por nome ou documento para localizar seus dados. | Alta |
| HU04 | Como administrador, quero cadastrar quartos para controlar as acomodações. | Alta |
| HU05 | Como recepcionista, quero consultar quartos e sua disponibilidade para orientar os hóspedes. | Alta |
| HU06 | Como recepcionista, quero realizar reservas para garantir uma acomodação ao hóspede. | Alta |
| HU07 | Como recepcionista, quero consultar reservas para acompanhar seus dados e situação. | Média |
| HU08 | Como recepcionista, quero cancelar reservas válidas para liberar quartos. | Média |
| HU09 | Como recepcionista, quero registrar o check-in para iniciar a hospedagem. | Alta |
| HU10 | Como recepcionista, quero registrar o check-out para finalizar a hospedagem e liberar o quarto. | Alta |
| HU11 | Como recepcionista, quero registrar pagamentos para controlar os valores recebidos. | Média |
| HU12 | Como administrador, quero cadastrar funcionários para manter os dados da equipe. | Média |
| HU13 | Como administrador, quero gerar relatórios de hospedagens para acompanhar a operação do hotel. | Média |
| HU14 | Como recepcionista, quero editar dados de hóspedes para mantê-los atualizados. | Média |
