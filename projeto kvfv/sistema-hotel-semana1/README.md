# Sistema de Gerenciamento de Hotel

Projeto da disciplina **Análise e Projeto de Sistemas**.

## Tecnologias obrigatórias

- Java 21
- JavaFX
- SQLite via `sqlite-jdbc`
- JDBC
- Maven
- Git + GitHub

## Como executar

É necessário ter Java 21 e Maven instalados.

No terminal, dentro da pasta do projeto:

```bash
mvn javafx:run
```

Na primeira execução, o sistema cria automaticamente a pasta `data/` e o banco SQLite `hotel.db`.
